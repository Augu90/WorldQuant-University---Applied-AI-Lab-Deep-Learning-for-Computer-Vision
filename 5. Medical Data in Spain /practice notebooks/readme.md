# Medical Image Generation with GANs #

In this project, I explore how neural networks can be used to generate new medical images. The focus is on Generative Adversarial Networks (GANs), both by building one from scratch and by working with a pre-trained model. The generated images include different types of medical data, such as X-rays and MRIs.

To make the project interactive, I developed a Streamlit web app that allows users to experiment with the GAN and visualize generated outputs in real time. The entire process is tracked and managed with Git and GitHub for version control and collaboration.

Key Learning Outcomes
How to create and train a GAN
How to use a pre-trained GAN to generate images and data
How to train a model using synthetic data from a GAN
How to build an interactive web app with Streamlit

This project combines deep learning, medical imaging, and web app development into a practical application that demonstrates how GANs can be used for data generation and experimentation.
